# Dudescord

Голос, видео, демонстрация экрана и чат для компании друзей — на своём сервере.

[In English](README.md)

- **Один сервер — одна комната.** Вы отправляете ссылку, каждый друг придумывает себе имя и
  пароль. Никаких аккаунтов на стороне, номеров телефонов, ничего не уходит с вашего сервера.
- **Работает в браузере** на компьютере и телефоне. Приложение (Windows, macOS) — тот же клиент в
  своём окне плюс глобальные горячие клавиши (рация, микрофон, звук) и оверлей с камерами
  друзей поверх игры.
- **Маленький.** Сервер — это [Galene](https://galene.org); ему хватает нескольких десятков
  мегабайт памяти, он уживается с чем угодно на самом дешёвом VPS.
- Интерфейс на русском и английском.

## Свой сервер за пять минут

Нужен VPS (или любая машина с Linux):

- Linux с systemd — Ubuntu, Debian и подобные; x86-64 или arm64;
- белый (публичный) IPv4-адрес;
- доступ root;
- 1 ядро и 512 МБ памяти достаточно.

Доменное имя **не нужно**: сервер получает сертификат прямо на IP-адрес.

Зайдите на машину и выполните:

```sh
curl -fsSL https://github.com/tapyard/dudescord/releases/latest/download/install.sh | sudo bash
```

Примерно через минуту появится ссылка-приглашение:

```
Dudescord is running. Send this link to your friends: everyone who opens it
chooses a name and a password. It works for any number of people; a new link
lasts 7 days.

  https://203.0.113.5/#invite=…
```

Откройте её сначала сами, придумайте имя и пароль — вы в комнате. Ту же ссылку отправьте
друзьям: она действует 7 дней и подходит любому числу людей. Ссылка на приложения — внизу
страницы входа вашего сервера.

Затем сделайте себя владельцем — приглашения и аккаунты появятся в настройках приложения, и
терминал больше не понадобится: `sudo dudescord owner <ваше имя>`, и обновите страницу.

### С помощью ИИ-агента

Дайте своему агенту (Claude Code, Codex, Cursor, …) доступ к машине и такую задачу:

> Установи сервер Dudescord на мой VPS по инструкции
> https://github.com/tapyard/dudescord/blob/main/AGENTS.md. Моё имя в комнате будет …

[AGENTS.md](AGENTS.md) написан для агентов (по-английски): проверки, команды по порядку, как
выглядит каждый ответ и что сказать вам в конце. Ни одна команда не ждёт ответа от человека,
ответы сервера с `--json` приходят в JSON, а настройки лежат в одном файле.

### Из приложения

Приложение может установить сервер само: на первой странице выберите «Создать свой сервер»,
введите адрес машины и пароль root, который прислал хостер, и своё имя и пароль для комнаты.

### Порты

Если у хостера в панели управления есть файрвол или «группы безопасности», эти порты нужно
открыть на вход. (`ufw` и `firewalld` на самой машине установщик открывает сам.)

| Порт | Зачем |
|---|---|
| TCP 80 | Let's Encrypt проверяет здесь адрес, когда выдаёт и продлевает сертификат |
| TCP 443 | сайт и подключение каждого клиента |
| TCP и UDP 1194 | ретранслятор для тех, у кого сеть не пропускает звук и видео напрямую |
| UDP 40000–49999 | голос и видео |

### С доменным именем

Направьте запись `A` на машину, дождитесь, пока имя начнёт открываться, затем:

```sh
curl -fsSL https://github.com/tapyard/dudescord/releases/latest/download/install.sh | sudo bash -s -- --address chat.example.org
```

### Если порты заняты

- Занят 443: `--port 8443` — адрес станет `https://203.0.113.5:8443`.
- Занят 1194 (например, OpenVPN): `--turn-port 3479`.
- Порт 80 занят вашим веб-сервером: оставьте его, пусть пересылает
  `/.well-known/acme-challenge/` на `127.0.0.1:8089`, и добавьте `--acme-port 8089`. Для nginx:

  ```nginx
  location ^~ /.well-known/acme-challenge/ {
      proxy_pass http://127.0.0.1:8089;
      proxy_set_header Host $host;
  }
  ```

Параметры запоминаются: при следующих запусках и обновлениях указывать их не нужно.

### Настройки

Настройки — один файл, `/opt/dudescord/dudescord.conf`: адрес, три порта и необязательный
e-mail, у каждой строки комментарий. Чтобы что-то поменять, отредактируйте файл и выполните
`sudo dudescord apply`: он проверит новые значения и перезапустит сервер. Чтобы разведать
обстановку до установки, добавьте к команде установки `--check`: он выполнит все проверки и
ничего не изменит.

## Управление

Всё делается одной командой на сервере, от имени root:

```sh
dudescord invite                  # новая ссылка-приглашение на 7 дней
dudescord invite --days 30
dudescord invites                 # действующие ссылки
dudescord revoke <ссылка>         # ссылка перестаёт работать; созданные по ней аккаунты остаются
dudescord users                   # у кого есть аккаунт
dudescord owner <имя>             # делает аккаунт владельцем: приглашения и аккаунты в настройках приложения
dudescord owner <имя> --remove    # …и снимает это право
dudescord reset-password <имя>    # печатает новый пароль тому, кто забыл свой
dudescord remove <имя>            # удаляет аккаунт
dudescord remove <имя> --restart  # …и отключает всех, кто сейчас в комнате
dudescord status                  # адрес, версия, сертификат, сколько людей подключено
dudescord config                  # файл настроек и что в нём
dudescord apply                   # применяет файл настроек после правки
dudescord update                  # свежий выпуск; аккаунты и настройки остаются
dudescord uninstall               # удаляет всё (сначала спросит)
```

Обновление и `apply` перезапускают сервер: всех отключит на несколько секунд, клиенты
подключатся сами. Команды, которые отвечают на вопрос, — все перечисленные, кроме `apply`,
`update` и `uninstall` — понимают `--json`: для скриптов и агентов.

**Владелец** видит в настройках приложения (шестерёнка) раздел «Сервер»: новые
ссылки-приглашения, список аккаунтов, новый пароль тому, кто забыл свой, удаление аккаунта.
Владельцев может быть несколько.

**Сменился адрес** (новый IP или появился домен): поменяйте `ADDRESS` в файле настроек и
выполните `dudescord apply` (или `dudescord update --address <новый>`).
Аккаунты остаются; люди открывают новый адрес и входят с тем же именем и паролем. Старые
ссылки-приглашения ведут на старый адрес — сделайте новую.

**Резервная копия**: `/opt/dudescord/server.json`, `/opt/dudescord/dudescord.conf`,
`/opt/dudescord/data/` и `/opt/dudescord/groups/` — это всё, что есть: настройки, аккаунты,
приглашения, сертификат. Аккаунты — один
файл, `/opt/dudescord/groups/main.json`: чтобы переехать на другую машину, установите сервер
там, скопируйте этот файл поверх нового, выполните `chown dudescord:dudescord` для него и
`systemctl restart dudescord`.

## Что делает установщик

Это один shell-скрипт — [прочитайте его](install.sh) перед запуском. Он:

- скачивает комплект выпуска с этой страницы и сверяет контрольную сумму;
- создаёт системного пользователя `dudescord` и каталог `/opt/dudescord`;
- получает сертификат Let's Encrypt и продлевает его по таймеру (сертификат на IP-адрес живёт
  шесть дней и продлевается каждые три);
- ставит три юнита systemd — `dudescord.service`, `dudescord-cert.service`,
  `dudescord-cert.timer` — и команду `/usr/local/bin/dudescord`;
- открывает свои порты в `ufw` или `firewalld`, если один из них включён.

Больше ничего на машине не трогается. Сервер работает от своего непривилегированного
пользователя с ограничением памяти 256 МБ. Пароль администратора создаётся на машине и лежит в
`/opt/dudescord/server.json`, читать его может только root.

## Если что-то пошло не так

- **«no certificate yet»** во время установки — Let's Encrypt не достучался до порта 80.
  Откройте TCP-порт 80 в файрволе хостера и запустите команду ещё раз: она продолжит с того
  места, где остановилась.
- **Люди заходят, но не слышат друг друга** — файрвол хостера не пропускает UDP 40000–49999
  или порт 1194.
- **Браузер говорит, что сертификат просрочен** — `dudescord status`, затем
  `journalctl -u dudescord-cert` покажет, почему не проходит продление (почти всегда порт 80).
- **Работает ли сервер?** — `dudescord status`, `journalctl -u dudescord -n 50`.

## Полезно знать

- Одна комната до 20 человек. Каналов, ролей и модерации нет: это комната для друзей.
- Сервер на домашнем компьютере не поддерживается: нужен белый IP-адрес и проброс портов, а у
  большинства домашних подключений нет ни того, ни другого. У самого дешёвого VPS есть.
- Проверено на Ubuntu 26.04 (x86-64). Другие дистрибутивы с systemd должны работать; если
  какой-то не работает — сообщите.
- Приложения: macOS на Apple Silicon (нотаризовано) и Windows x64 (не подписано — Windows
  покажет «Система Windows защитила ваш компьютер»: «Подробнее» → «Выполнить в любом случае»).
